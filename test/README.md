# Verification coverage

All tests use the pinned Solidity 0.8.26/Cancun configuration and vendored dependencies. They run offline, with no environment reads or mutations, RPC, FFI, or custom filesystem permissions. Fixtures use Foundry's compiled artifact loader and actual CREATE2 construction, preserving hook address validation and constructor behavior. Nothing delivered imports `test/scratch/` or `.imd/reads/`.

```sh
forge build
FOUNDRY_FUZZ_SEED=0xc84cd5248922f87e15fc9a5277917df94609ac4718540c324edc66cc0c98531b forge test
forge fmt --check
forge script script/MineSalt.s.sol --sig "verifyRecorded()"
```

The "Vault" in several suite names refers to the hook's basket (its receipts and position), not to the removed v1 wrapper contract, whose own test file was deleted with it. The independent accounting model records actual wallet and router flows rather than deriving its book from `totalAssets()`. LP NAV **plus fee liabilities** must match physical custody within an operation-count rounding allowance. The sample-only swap callback must never update the keeper timestamp.

These tests do not establish compatibility with the pinned chain's extended swap ABI or constitute an independent security audit. Deployment and adversarial review responsibilities are documented in the root README.

## Local verification result

See the root README's "Factory deployment and CREATE2 parameters" for the bytecode sizes; the hook runtime is 24,376 bytes against the 24,576-byte EIP-170 limit with the pinned compiler settings. The verification run recorded by this delivery is reported in the task result. Forge emits lint advisories about bounded casts, timestamp gates, exact balance checks and guarded external calls; this result is not a clean static-analysis audit.

The factory assignment passed all 160 tests (including 18 factory tests) using the seed above. `CreatePoolManagerHarness` supplies the requested createPool extension and a fixture-only 1:1 price; the supplied live manager was not queried. Tests explicitly reject an upstream manager without that extension. The production factory and its immutable code stores are deployed with CREATE in these tests, not injected with `vm.etch`.
